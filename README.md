## 💻Sobre a Atividade💻
Durante a atividade, foi feito um trabalho com o objetivo de criar uma página utilizando apenas HTML para a empresa GameZone Retro, dessa forma, com cunho educacional de testar os conhecimentos aprendidos durante a sala de aula, nós deveriamos:

*Criar apenas 50 linhas de código HTML.
*Usar apenas HTML puro e simples.
*Incluir uma estrutura básica, lista, navegação, imagem e tabela.
*Usar de tema a GameZone Retro.
*Ter funcionalidade sobre aparência.

A atividade está disponivel dentro do repositório em formato pdf.

## Critérios de Avaliação
* Respeitar o limite de 50 linhas.
* Implementar os 5 elementos essenciais.
* Código limpo e organizado.
* Funcionalidade dos links
* Estrutura do HTML válida.
